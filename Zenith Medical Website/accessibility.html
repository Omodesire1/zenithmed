Accessibility Commitment

Last updated: [PLACEHOLDER DATE]

Zenith Medical Centre is committed to providing an accessible website and clinic environment for all patients and visitors, in accordance with the Accessibility for Ontarians with Disabilities Act (AODA) and the Web Content Accessibility Guidelines (WCAG) 2.1, Level AA.

Website Accessibility Features

  • Semantic HTML structure with descriptive headings and landmarks
  • Keyboard-navigable menus, forms and interactive components
  • Visible focus indicators on all interactive elements
  • Descriptive alternative text for meaningful images
  • Accessible colour contrast throughout the design
  • Labelled form fields with clear error messaging
  • Screen-reader-compatible accordion, navigation and form components
  • A "Skip to main content" link on every page
